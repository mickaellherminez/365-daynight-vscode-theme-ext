Every syntax color, measured.

Each bar is the text contrast against the editor background, using the exact colors of . The markers show the 4.5:1 and 7:1 text contrast thresholds.

Contrast = (lighter relative luminance + 0.05) / (darker relative luminance + 0.05). Measurements apply to these text colors on the editor background; they do not certify the whole interface. Method and limits · Download the audit data.

How it is built

  1. 1

    One palette per month

    Each month starts from a seasonal mood: frost in January, a lagoon in July, autumn leaves in October.

  2. 2

    Generated themes

    A script builds the four themes of a month from its palette. CI compares the published files with the generator, byte for byte.

  3. 3

    Automatic audit

    Contrast, simulated color vision, font styles and the difference between months are measured for every theme.

    • Contrast
    • Simulated color vision
    • Font styles
    • Difference between months
  4. 4Coming

    Testing with real people

    Simulations do not replace real eyes. This step has not been done yet: you can help.
