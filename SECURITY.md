# Security policy

## Supported versions

Security fixes go into the latest release and the latest pre-release. Please update before reporting a problem.

## Reporting a vulnerability

Please do not open a public issue. Use [Report a vulnerability](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext/security/advisories/new) on GitHub instead, which keeps the report private.

Please include the extension version, your editor and version, the steps to reproduce the problem, and its possible impact.

## Scope

The extension has no runtime dependencies and makes no network calls. It only changes the color theme setting of your editor. Reports about the build and publishing workflows of this repository are welcome too.
