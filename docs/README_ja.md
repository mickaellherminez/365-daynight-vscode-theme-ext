# 365 Day & Night Themes – 毎月使えるアクセシブルな VS Code テーマ

**Visual Studio Code 用の 36 種類のカラーテーマ：1 年の各月に、ライト・ダーク・ハイコントラストの 3 種類を用意しています。** ワンクリックで昼と夜を切り替えることも、拡張機能に自動で任せることもできます。すべてのテーマは読みやすさ（WCAG コントラスト）と色覚多様性への対応をテスト済みです。

## おすすめの理由

- 🗓️ **毎月、新しい雰囲気に。** 1 月は雪と冬の青、3 月は春の緑、7 月は真夏の太陽、10 月は秋の色、12 月は暖炉のぬくもり。エディターが季節とともに移り変わります。
- ☀️🌙 **昼も夜もぴったり。** 各月に、昼用のライトテーマ、夜用のダークテーマ、最大限の読みやすさが必要なときのハイコントラストテーマがあります。
- 🔁 **ワンクリックで切り替え。** ステータスバーのボタンで、ライト・ダーク・ハイコントラストを順に切り替えられます。
- ⏰ **自動モード（任意）。** 拡張機能が当月のテーマを自動で適用します。昼はライト、夜はダークです。
- 👁️ **目にやさしく、誰にでも読みやすい。** すべてのテキストが WCAG のコントラスト基準を満たし、シンタックスの色は色覚に特性のある方にも区別しやすくなっています。
- 🖥️ **細部まで完成されたテーマ。** エディター、サイドバー、タブ、ターミナル、デバッグコンソール、通知、ステータスバーまで、すべてデザイン済みです。デフォルトの色に戻る部分はありません。

## インストール

**VS Code から：** 拡張機能ビューを開き（`Ctrl+Shift+X`、Mac では `Cmd+Shift+X`）、**365 Day & Night Themes** を検索して**インストール**をクリックします。

**Marketplace から：** [365 Day & Night Themes をインストール](https://marketplace.visualstudio.com/items?itemName=mickaellherminez.365-daynight-vscode-theme-ext)。

**コマンドラインから：**

```sh
code --install-extension mickaellherminez.365-daynight-vscode-theme-ext
```

Visual Studio Code 1.96 以降が必要です。

## はじめかた

1. テーマの選択画面を開きます：`Ctrl+K` を押してから `Ctrl+T`（Mac では `Cmd+K` を押してから `Cmd+T`）。
2. **365** と入力すると 36 種類のテーマが表示されます。例：`365 10-October Dark`。
3. 1 つ選べば完了です！

**ステータスバーのボタン**（右下：`LGT`、`DRK`、`HCT`）で、当月のライト・ダーク・ハイコントラスト版を切り替えられます。

## 昼と夜の自動切り替え

エディターを時刻に合わせたいですか？自動モードを有効にしましょう：

1. 設定を開き（`Ctrl+,` または `Cmd+,`）、**365DayNight** を検索します。
2. **365DayNight: Enable** にチェックを入れます。

または `settings.json` に次を追加します：

```json
{
  "365DayNight.enable": true,
  "365DayNight.mode": "auto"
}
```

| モード | 動作 |
| --- | --- |
| `auto` | 7:00〜19:00 はライトテーマ、それ以外はダークテーマ |
| `day` | 常に当月のライトテーマ |
| `night` | 常に当月のダークテーマ |

毎月 1 日には、新しい月のテーマへ自動で切り替わります。

知っておきたいこと：

- **決めるのはあなたです。** 自動モードは初期状態でオフです。あなたの許可なくテーマが変わることはありません。
- **手動の選択を尊重します。** 手動でテーマを選んだ場合は、次の期間の切り替わり（昼から夜、または新しい月）までそのまま維持されます。
- **ハイコントラストはハイコントラストのまま。** ハイコントラストテーマを使っている場合、自動モードは月だけを更新し、コントラストのレベルは変えません。

## アクセシビリティを最優先に

すべてのテーマは、130 項目を超える自動アクセシビリティ監査に合格しています：

- **読みやすい文字：** エディターの文字とシンタックスの色は、ライトとダークで **4.5:1（WCAG AA）** 以上、ハイコントラストで **7:1（WCAG AAA）** 以上のコントラストを確保しています。
- **色覚多様性に配慮：** シンタックスの色（キーワード、関数、文字列、数値、クラス、コメント）と通知（エラー、警告、Git の変更）を **1 型・2 型・3 型色覚** でシミュレーションし、区別できることを確認しています。
- **色だけに頼らない：** コメント、パラメーター、属性は*斜体*、非推奨のコードは~~取り消し線~~、無効なコードには下線を付けています。
- **どこでも見える選択範囲：** エディター、ターミナル、デバッグコンソールで選択範囲がはっきり見え、検索結果と混同することはありません。
- **ハイコントラストテーマ：** 選択した文字は水色の背景に黒で表示され、すべてのパネルに見やすい枠線とはっきりしたキーボードフォーカスの輪郭があります。

読みにくい色がありましたら、[issue を作成](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext/issues)してください。アクセシビリティに関するご意見はいつでも歓迎です。

## コマンド

コマンドパレット（`Ctrl+Shift+P` または `Cmd+Shift+P`）を開き、**365** と入力します：

| コマンド | 動作 |
| --- | --- |
| `365: Toggle between Light, Dark and High Contrast themes` | ライト → ダーク → ハイコントラストを順に切り替え（ステータスバーのボタンと同じ） |
| `365: Apply Light theme` | 当月のライトテーマを適用 |
| `365: Apply Dark theme` | 当月のダークテーマを適用 |
| `365: Apply High Contrast theme` | 当月のハイコントラストテーマを適用 |

これらのコマンドは、エディターの右クリックメニュー **365 Themes** からも使えます。お好みのキーボードショートカットを割り当てることもできます（`Ctrl+K Ctrl+S`）。

## 設定

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| `365DayNight.enable` | `false` | 当月のテーマを自動で適用 |
| `365DayNight.mode` | `auto` | `auto`（時刻に応じて）、`day`（常にライト）、`night`（常にダーク） |

## よくある質問

**VS Code をライトテーマとダークテーマで自動的に切り替えるには？**
拡張機能をインストールし、`"365DayNight.enable": true` を設定します。7:00〜19:00 はライトテーマ、夜間はダークテーマが適用されます。

**色覚多様性に配慮した VS Code テーマはありますか？**
はい。36 種類すべてのテーマを 1 型・2 型・3 型色覚のシミュレーションでテストし、斜体・下線・取り消し線も使って、情報が色だけに依存しないようにしています。

**拡張機能が勝手にテーマを変えることはありますか？**
いいえ。自動モードは初期状態でオフです。オフのままなら、テーマを選んだときかステータスバーのボタンを押したときにだけ変わります。

**1 つのテーマだけを使うことはできますか？たとえば October Dark など。**
もちろんです。テーマの選択画面（`Ctrl+K Ctrl+T`）で選び、自動モードをオフのままにしてください。

**ハイコントラストテーマは何のためにありますか？**
ロービジョンの方、とても明るい環境、長時間のコーディング向けです。最大限のコントラスト（AAA）、見やすい枠線、はっきりしたフォーカスの輪郭を備えています。

**祝日のテーマはありますか？**
まだありません。新年、イースター、ハロウィン、クリスマスのテーマを予定しています。[GitHub のプロジェクト](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext)をフォローしてお待ちください。
