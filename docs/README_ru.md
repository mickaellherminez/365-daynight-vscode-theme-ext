# 365 Day & Night Themes – доступные темы VS Code на каждый месяц

**36 цветовых тем для Visual Studio Code: светлая, тёмная и высококонтрастная тема для каждого месяца года.** Переключайтесь между днём и ночью одним щелчком или доверьте это расширению. Каждая тема проверена на читаемость (контраст WCAG) и на дальтонизм.

## Почему вам понравится

- 🗓️ **Новый облик каждый месяц.** Снег и зимняя синева в январе, весенняя зелень в марте, яркое солнце в июле, осенние краски в октябре, уют у камина в декабре: редактор следует за временами года.
- ☀️🌙 **День и ночь всегда в паре.** У каждого месяца есть светлая тема для дня, тёмная для вечера и высококонтрастная, когда нужна максимальная читаемость.
- 🔁 **Переключение в один щелчок.** Кнопка в строке состояния переключает светлую, тёмную и высококонтрастную темы.
- ⏰ **Автоматический режим (по желанию).** Расширение может само применять тему текущего месяца: светлую днём и тёмную ночью.
- 👁️ **Бережно для глаз и читаемо для всех.** Весь текст соответствует уровням контраста WCAG, а цвета синтаксиса остаются различимыми для людей с дальтонизмом.
- 🖥️ **Полные темы.** Редактор, боковая панель, вкладки, терминал, консоль отладки, уведомления и строка состояния — оформлено всё, ничего не возвращается к цветам по умолчанию.

## Установка

**В VS Code:** откройте панель расширений (`Ctrl+Shift+X`, на Mac `Cmd+Shift+X`), найдите **365 Day & Night Themes** и нажмите **Установить**.

**В Marketplace:** [установить 365 Day & Night Themes](https://marketplace.visualstudio.com/items?itemName=mickaellherminez.365-daynight-vscode-theme-ext).

**Из командной строки:**

```sh
code --install-extension mickaellherminez.365-daynight-vscode-theme-ext
```

Требуется Visual Studio Code 1.96 или новее.

## Начало работы

1. Откройте выбор темы: `Ctrl+K`, затем `Ctrl+T` (на Mac `Cmd+K`, затем `Cmd+T`).
2. Введите **365**, чтобы увидеть все 36 тем, например `365 10-October Dark`.
3. Выберите тему. Готово!

**Кнопка в строке состояния** (справа внизу: `LGT`, `DRK` или `HCT`) переключает светлую, тёмную и высококонтрастную версии текущего месяца.

## Автоматическое переключение дня и ночи

Хотите, чтобы редактор следовал за часами? Включите автоматический режим:

1. Откройте настройки (`Ctrl+,` или `Cmd+,`) и найдите **365DayNight**.
2. Отметьте **365DayNight: Enable**.

Или добавьте в `settings.json`:

```json
{
  "365DayNight.enable": true,
  "365DayNight.mode": "auto"
}
```

| Режим | Что делает |
| --- | --- |
| `auto` | Светлая тема с 7:00 до 19:00, тёмная — в остальное время |
| `day` | Всегда светлая тема текущего месяца |
| `night` | Всегда тёмная тема текущего месяца |

Кроме того, в первый день каждого месяца расширение переходит на тему нового месяца.

Полезно знать:

- **Решаете вы.** Автоматический режим по умолчанию выключен: расширение никогда не меняет тему без вашего согласия.
- **Ваш выбор сохраняется.** Если вы выбрали тему вручную, она остаётся до следующей смены периода (день/ночь или новый месяц).
- **Высокий контраст остаётся высоким.** Если вы используете высококонтрастную тему, автоматический режим обновляет только месяц, но не уровень контраста.

## Доступность прежде всего

Каждая тема проходит автоматизированный аудит доступности из более чем 130 проверок:

- **Читаемый текст:** текст редактора и цвета синтаксиса имеют контраст не ниже **4,5:1 (WCAG AA)** в светлых и тёмных темах и **7:1 (WCAG AAA)** в высококонтрастных.
- **Удобно при дальтонизме:** цвета синтаксиса (ключевые слова, функции, строки, числа, классы, комментарии) и оповещения (ошибки, предупреждения, изменения Git) моделируются для **протанопии, дейтеранопии и тританопии**, чтобы они оставались различимыми.
- **Не только цвет:** комментарии, параметры и атрибуты выделены *курсивом*, устаревший код — ~~зачёркнут~~, недопустимый код — подчёркнут.
- **Выделение видно везде:** выделенный текст хорошо заметен в редакторе, терминале и консоли отладки и никогда не путается с результатами поиска.
- **Высококонтрастные темы:** выделенный текст становится чёрным на светло-голубом, у всех панелей есть видимые границы и чёткая рамка фокуса клавиатуры.

Какой-то цвет трудно читать? [Создайте issue](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext/issues) — отзывы о доступности всегда приветствуются.

## Команды

Откройте палитру команд (`Ctrl+Shift+P` или `Cmd+Shift+P`) и введите **365**:

| Команда | Действие |
| --- | --- |
| `365: Toggle between Light, Dark and High Contrast themes` | Переключает светлую → тёмную → высококонтрастную (как кнопка в строке состояния) |
| `365: Apply Light theme` | Применяет светлую тему текущего месяца |
| `365: Apply Dark theme` | Применяет тёмную тему текущего месяца |
| `365: Apply High Contrast theme` | Применяет высококонтрастную тему текущего месяца |

Эти команды также доступны в меню **365 Themes** по правому щелчку в редакторе. Им можно назначить свои сочетания клавиш (`Ctrl+K Ctrl+S`).

## Настройки

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `365DayNight.enable` | `false` | Автоматически применяет тему текущего месяца |
| `365DayNight.mode` | `auto` | `auto` (по времени суток), `day` (всегда светлая) или `night` (всегда тёмная) |

## Частые вопросы

**Как автоматически переключать VS Code между светлой и тёмной темой?**
Установите расширение и задайте `"365DayNight.enable": true`. Светлая тема применяется с 7:00 до 19:00, тёмная — ночью.

**Есть ли тема VS Code для людей с дальтонизмом?**
Да. Все 36 тем проверены моделированием протанопии, дейтеранопии и тританопии и используют курсив, подчёркивание и зачёркивание, чтобы информация никогда не зависела только от цвета.

**Изменит ли расширение тему без спроса?**
Нет. Автоматический режим по умолчанию выключен. Без него тема меняется, только когда вы выбираете её сами или нажимаете кнопку в строке состояния.

**Можно ли пользоваться только одной темой, например October Dark?**
Конечно. Выберите её в списке тем (`Ctrl+K Ctrl+T`) и не включайте автоматический режим.

**Для чего нужны высококонтрастные темы?**
Они созданы для слабого зрения, очень яркого освещения или долгих сеансов программирования: максимальный контраст (AAA), видимые границы и чёткая рамка фокуса.

**Есть ли праздничные темы?**
Пока нет. Запланированы темы для Нового года, Пасхи, Хэллоуина и Рождества. Следите за [проектом на GitHub](https://github.com/mickaellherminez/365-daynight-vscode-theme-ext).
